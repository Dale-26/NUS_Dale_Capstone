# Machine learning and AI

Run commands from the repository root; see ../README.md for environment setup, all commands and limitations. `python -m capstone_part3.train` regenerates the comparison, models, SHAP, unsupervised results, MLflow records, monitoring and recommendations. `python -m capstone_part3.api` starts the localhost deployment mock-up.

No accident dataset was sourced. The high_risk label is a documented congestion/weather proxy. Do not interpret it as real accident likelihood. Fixed seed 42 and chronological train/validation/test boundaries support reproducibility. The final report covers every task; the separate bias report covers coverage, proxy risks, subgroup errors, governance and sustainability.
